### 新架构：initramfs 接管启动
- 新增 `app/src/main/assets/initrd.cpio.gz`（1.47 MB），由 `.work/build-initramfs.py` 生成（自写 newc cpio，源在 `.work/initramfs/{init,boot.sh}`）。
- `/init`：挂 squashfs→tmpfs 覆盖 /var /run /tmp→ext4 挂 /var/lib/containers（失败则 mke2fs）→**整个 /etc 换 tmpfs**（bind 参照+拷回）→拷 busybox 到 /run /var /tmp 三处→`chroot /mnt /run/busybox sh /run/docklet-boot.sh`。
- `boot.sh`(PID1)：cgroup2 / resolv.conf / SLIRP 网络 / binfmt / storage.conf+registries.conf+containers.conf / podman service / **轮询 /proc/net/tcp 2375 state=0A 才算 READY**。

### 六个真实 bug（改动 initramfs 必看）
1. **CRLF**：`#!/bin/busybox sh\r` → 内核取到 `sh\r` → `applet not found` → PID1 退出 panic。build 脚本里强制归一化 LF。
2. **switch_root → chroot**：switch_root 的 bind 会遮住子挂载与 initramfs /bin，报 Symbolic link loop。
3. **binfmt 注册必须写字面转义**：`printf '\x7f...\x00...'` 会把 \x00 写成真实 NUL，内核按 C 字符串截断 → 注册出「匹配所有 ELF」的坏规则 → **之后所有 exec 都 ELOOP**。正确：`printf '%s\n' ':qemu-x86_64:M::\x7fELF...'`。
4. **/etc 必须整体 tmpfs**：只覆盖 /etc/containers 不够，resolv.conf/hosts 也要可写。
5. **resolv.conf 要有 `nameserver ` 前缀**，裸 IP 会被忽略。
6. **`read` 是内建**，不能写 `$BB read`（会 exec 不存在的 applet）。

### 真机环境三个坑
- **App UID 出网受待机分组限制**：`run-as` 起 QEMU 时 App 在后台 → u0_a958 出网被拦（shell UID 正常）。需 `am set-standby-bucket ... active` + `cmd deviceidle whitelist +<pkg>`。产品上前台服务运行时不受影响。
- **docker.io 被 DNS 污染**：registry-1.docker.io 解析到 69.171.229.11。已在 registries.conf 内置镜像回退：docker.m.daocloud.io → docker.1panel.live → hub.rat.dev（三个实测可达），可用 `docklet.mirror=` 覆盖。
- **adb server 每次 Bash 调用都会重启**，forward 会丢；`adb forward` 与 `curl` 必须放在同一次 shell 调用里。
